# Library Management System (MVP)

This is a group software development project built using Agile methodology, designed to solve real-world problems faced by traditional libraries. 

## Project Overview

We see today traditional libraries often face challenges in managing large inventories, ensuring efficient user access, and maintaining fast, accurate book searches. 
To address this, our team developed a **Library Management System (LMS)** that automates:
- Book inventory tracking
- Borrowing & returning
- Admin management
- User search & verification

This project was completed by a 14-member team and structured into 4 agile sprints, each representing a phase in the development lifecycle.

## Roles Breakdown

- **System Analysts**: Designed ERD, use cases, activity diagrams
- **Developers**: Implemented frontend/backend features (Login, Book CRUD, Borrowing)
- **Designers**: Built UI prototypes (via Figma)
- **Testers**: Created test cases, documented bugs, ensured app functionality

## 🛠 Tech Stack
- Java (Eclipse)
- SQL (MySQL or SQL Server)
- Figma (UI Design)
- Microsoft Word & PowerPoint (Documentation)

##  Sprint Highlights
**Sprint 1**: Setup use cases, ERD, login database  
**Sprint 2**: Book add/search features  
**Sprint 3**: Borrowing logic, verification  
**Sprint 4**: UI refinement, final testing
